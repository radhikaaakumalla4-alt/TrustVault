# TrustVault - AI Usage and Corrections

## Project Overview
TrustVault is a secure document-sharing system developed using Python, Flask, SQLite, HTML and CSS.

## AI Assistance
AI assistance was used for:
- Flask application development.
- Login authentication and role-based access.
- Database table creation and SQL queries.
- Document upload and download functionality.
- Managing document permissions.
- Activity log implementation.
- HTML and CSS UI design.
- Debugging and testing.

## Mistakes and Corrections

### 1. TemplateNotFound Error
- Problem: Flask could not find the required HTML template.
- Correction: Checked the templates folder and corrected the template filename and location.

### 2. Duplicate Routes
- Problem: Duplicate Flask route definitions caused conflicts.
- Correction: Reviewed the application and removed duplicate route definitions.

### 3. Document Permissions
- Problem: Viewer access needed to be restricted to authorized documents.
- Correction: Updated permission checks to allow viewers to access only shared documents.

### 4. Database Errors
- Problem: SQL queries and indentation required corrections.
- Correction: Reviewed database queries and corrected the code structure.

## Testing
- Tested Admin, Owner and Viewer login.
- Tested document upload and download.
- Tested document-sharing permissions.
- Tested unauthorized access restrictions.
- Tested activity logs.
