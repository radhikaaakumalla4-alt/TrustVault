# 🛡️ TrustVault
### Secure Document Sharing System with Role-Based Access Control and Audit Logs

## 📌 Project Overview
TrustVault is a secure document-sharing web application that allows users to upload, share, access, and manage documents with role-based permissions.

It helps protect confidential documents by ensuring that only authorized users can access them. It also maintains activity logs to track important document activities.

## 🎯 Objectives
- Provide secure document sharing.
- Implement role-based access control.
- Allow document owners to manage permissions.
- Revoke document access when required.
- Maintain activity logs for document activities.

## ✨ Key Features

- **Admin Login:** Manage users, documents, permissions, and activity logs.
- **Owner Login:** Upload documents and share them with viewers.
- **Viewer Login:** Access documents shared with them.
- **Document Upload:** Upload supported files securely.
- **Document Sharing:** Grant document-specific access.
- **Permission Management:** Grant and revoke viewer permissions.
- **Secure Downloads:** Restrict downloads to authorized users.
- **Activity Logs:** Track important user and document activities.

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Git & GitHub
- Render (Deployment)

## 👥 User Roles

1. **Admin** – Manages users, documents, and activity logs.
2. **Owner** – Uploads documents and controls sharing permissions.
3. **Viewer** – Views and downloads authorized documents.

## 🔐 Security Features

- Password hashing.
- Session-based authentication.
- Role-based access control.
- Document-specific permissions.
- Permission revocation.
- Activity logging.
